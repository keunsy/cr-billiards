台球切角三角形 - 三种顶点对比（30° 切角）

白球 C 打目标球 O 进袋口 P，切角 ≈ 30°

📐 理论说明：切角（Cut Angle）与切割线

  • 标准切角定义：白球运动方向（C→G）与进球线（O→P）的夹角。G（假想球中心）是唯一精确的顶点
  • 为什么 G 最精确？ — 白球必须走到 G 的位置才能把目标球送向袋口，C→G = 白球实际运动方向
  • O（目标球中心）= 简化近似 — 目标球看得见而假想球看不见，部分教材用 O 代替 G
  • T（接触点）= 折中近似 — 精度介于 O 和 G 之间
  • 差异随角度增大而增大（见下表），取决于白球与目标球的距离

📊 三种顶点角度差异对比

白球固定在 G 处精确切角位置时，O 和 T 顶点的实际角度：

标准切角 (G) O 角度 O 偏差 T 角度 T 偏差
30° 27.02° -2.98° 28.44° -1.56°
45° 40.72° -4.28° 42.78° -2.22°

⚠ 结论：O 最大偏差近 6°，T 最大偏差约 3°，角度越大偏差越大。G 始终精确。

✂️ 切割线（Cut Line）

  • 切割线 = 瞄准线（C→G 方向）穿过目标球时，在球面上形成的弦
  • 切割线显示了白球"切过"目标球的位置和宽度
  • 弦长 / 球直径 = 切割比例 — 1.0 = 正中穿过（全厚），越小越薄
  • 30° 切角：切割线约在目标球偏心位置，sin 30° = 0.5 → 半球碰撞
  • 常见厚薄：0° = 全厚（弦 = 直径）、30° ≈ 半球、45° ≈ 1/4、90° = 擦边（弦→0）

三角函数关系

  • sin θ = 对边 / 斜边 — sin 30° = 0.5（半球）
  • cos θ = 邻边 / 斜边 — cos 30° ≈ 0.866
  • 台球中 sin θ 衡量切球厚薄：sin 0° = 全厚，sin 90° = 极薄

推荐

  • App 中应使用 G（假想球中心） — 既精确又与幻影球虚线圆自然配合
